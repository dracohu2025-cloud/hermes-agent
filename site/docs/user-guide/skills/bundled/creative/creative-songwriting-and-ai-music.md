# 歌曲创作与 AI 音乐生成 {#songwriting-ai-music-generation}

以下所有内容均为**指南**，而非规则。艺术本就刻意打破规则。
使用对歌曲有用的部分，忽略无用的部分。

---

## 1. 歌曲结构（选择一种或自行创造） {#1-song-structure-pick-one-or-invent-your-own}

常见骨架——可根据需要混合、修改或舍弃：

```
ABABCB  主歌/副歌/主歌/副歌/桥段/副歌    （大多数流行/摇滚）
AABA    主歌/主歌/桥段/主歌（基于重复句）  （爵士标准曲、民谣）
ABAB    主歌/副歌交替                    （简单直接）
AAA     主歌/主歌/主歌（无副歌的叙事体）  （民谣、讲故事）
```

六个构建模块：
- 前奏（Intro）——营造氛围，吸引听众
- 主歌（Verse）——故事、细节、世界观构建
- 预副歌（Pre-Chorus）——可选，在副歌前制造张力
- 副歌（Chorus）——情感核心，让人记住的部分
- 桥段（Bridge）——转折，视角或调性的变化
- 尾声（Outro）——告别，可呼应或颠覆前文

你不需要全部使用。有些好歌只有一个不断演变的段落。
结构服务于情感，而非相反。

## 2. 押韵、格律与音韵 {#2-rhyme-meter-and-sound}

押韵类型（从严格到宽松）：
- 完美押韵：lean/mean
- 家族押韵：crate/braid
- 元音押韵：had/glass（相同元音，不同结尾）
- 辅音押韵：scene/when（不同元音，相似结尾）
- 近似/斜韵：足以暗示联系，但不完全锁定

混合使用。全部完美押韵听起来像儿歌。
全部斜韵听起来像偷懒。真正的魅力在于混合。

内部押韵：在行内押韵，而不仅仅在行尾。
  “We pruned the lies from bleeding trees / Distilled the storm
   from entropy” — “lies/flies,” “trees/entropy” 创造了内部回声。

格律：重读音节与非重读音节的节奏。
- 平行行之间的音节数匹配有助于演唱
- 重读音节比总音节数更重要
- 大声读出来。如果卡顿，格律需要调整。
- 有意打破格律可以制造强调或惊喜

## 3. 情感弧线与动态 {#3-emotional-arc-and-dynamics}

把歌曲看作一段旅程，而非平坦的道路。

能量映射（大致思路，非规定）：
  前奏：2-3  |  主歌：5-6  |  预副歌：7
  副歌：8-9  |  桥段：变化  |  最终副歌：9-10

最强大的动态技巧：**对比**。
- 尖叫前的低语比直接尖叫更有冲击力
- 稀疏后密集。慢后快。低后高。
- 高潮只因为铺垫才有效
- 沉默也是一种乐器
"从低语到咆哮再到低语"——从私密开始，逐步推向高潮，再回归脆弱。适用于民谣、史诗、颂歌。

## 4. 写出有效的歌词 {#4-writing-lyrics-that-work}

展示，而非直白陈述（通常如此）：
- "我很伤心" = 平淡
- "你的卫衣还挂在门边的钩子上" = 生动
- 但有时直白地说出"我献出生命"本身就是力量

副歌钩子：
- 人们记住、哼唱、重复的那句词
- 通常是歌名或核心短语
- 当旋律、歌词和情感三者一致时效果最佳
- 放在最能打动人心的位置（通常是副歌的第一句或最后一句）

韵律——歌词与旋律相互支撑：
- 稳定的情感（解决、平静）搭配平稳的旋律、完美押韵、解决和弦
- 不稳定的情感（渴望、怀疑）搭配游走的旋律、近似押韵、未解决和弦
- 主歌旋律通常较低，副歌较高
- 但如果歌曲需要，也可以反过来

避免（除非你刻意为之）：
- 自动化的陈词滥调（未经铺垫就写"金子般的心"）
- 为了押韵强行调整语序（"尤达式说话"）
- 每个段落能量相同（动态平淡）
- 把初稿奉为神圣——修改也是创作

## 5. 恶搞与改编 {#5-parody-and-adaptation}

用新歌词重写现有歌曲时：

骨架：先映射原曲结构。
- 统计每行音节数
- 标记押韵方案（ABAB、AABB等）
- 识别哪些音节是重读的
- 注意长音/持续音落在哪里

填入新词：
- 将重读音节匹配到原曲的相同节拍
- 总音节数可以灵活调整1-2个非重读音节
- 在长音上，尽量匹配原曲的元音音色
  （如果原曲在"LOOOVE"上保持"oo"元音，那么"FOOOD"比"LIFE"更合适）
- 关键位置使用单音节替换可保持节奏完整
  （Crime -> Code, Snake -> Noose）
- 用原曲旋律唱你的新词——如果卡顿，就修改

概念：
- 选择一个足够强大的概念来支撑整首歌
- 从标题/钩子出发，向外构建
- 先大量生成原始素材（双关语、短语、意象），
  然后将最好的素材填入结构
- 如果你需要在某个特定位置放一句词，反向推导押韵方案来铺垫

保留一些原词：保留几行原词或原结构能增加辨识度，让听众感受到关联。

## 6. Suno AI 提示词工程 {#6-suno-ai-prompt-engineering}

### 风格/流派描述字段 {#style-genre-description-field}

公式（按需调整）：
  流派 + 情绪 + 时代 + 乐器 + 人声风格 + 制作 + 动态

```
差：  "悲伤摇滚歌曲"
好： "电影配乐式管弦乐间谍惊悚片，1960年代冷战时期，烟嗓性感女声，大乐队爵士，铜管组包括小号和圆号，铺陈的弦乐，小调，复古模拟温暖感"
```

描述旅程，而不仅仅是流派：
```
"以稀疏钢琴上的低语开场。逐渐加入弱音铜管。副歌时全乐团爆发。第二段主歌以原始呐喊般的强度爆发。尾声回归孤寂的钢琴和脆弱的低语，渐弱至无声。"
```
小贴士：
- V4.5+ 版本支持在风格字段中使用最多 1000 个字符——请充分利用
- 不要使用艺术家名称或商标。改用声音描述。
  "1960 年代冷战间谍惊悚片铜管乐" 而不是 "詹姆斯·邦德风格"
  "90 年代垃圾摇滚" 而不是 "涅槃风格"
- 有偏好的话，请指定 BPM 和调性
- 使用排除风格字段来指定你**不**想要的内容
- 意想不到的风格组合可能是宝藏："波萨诺瓦陷阱"、
  "阿巴拉契亚哥特"、"芯片音乐爵士"
- 构建一个声音角色，而不仅仅是性别：
  "一位饱经风霜的烟嗓女歌手，声音略带沙哑，
  开始时脆弱，逐渐爆发出毁灭性的力量"

### 元标签（放在歌词字段的 [方括号] 内） {#metatags-place-in-brackets-inside-lyrics-field}

结构：
  [前奏] [主歌] [主歌 1] [预副歌] [副歌]
  [后副歌] [钩子] [桥段] [间奏]
  [器乐] [器乐间奏] [吉他独奏]
  [分解] [铺垫] [尾声] [静默] [结束]

人声表现：
  [低语] [念白] [强音] [假声] [有力]
  [深情] [沙哑] [气声] [流畅] [粗粝]
  [断音] [连音] [颤音] [花腔]
  [和声] [合唱] [和声副歌]

动态：
  [高能量] [低能量] [能量渐强] [爆发]
  [情感高潮] [逐渐增强] [管弦乐渐强]
  [安静编曲] [张力下降] [慢下来]

性别：
  [女声] [男声]

氛围：
  [忧郁] [欣快] [怀旧] [激进]
  [梦幻] [亲密] [黑暗氛围]

音效：
  [黑胶噼啪声] [雨声] [掌声] [静电] [雷声]

在风格字段和歌词中都放置标签以加强效果。
每段最多使用 5-8 个标签——太多会混淆 AI。
不要自相矛盾（同一段中同时出现 [平静] 和 [激进]）。

### 自定义模式 {#custom-mode}
- 对于严肃创作，始终使用自定义模式（分开的风格 + 歌词）
- 歌词字段限制：约 3,000 个字符（约 40-60 行）
- 始终添加结构标签——否则 Suno 会默认使用
  平淡的主歌/副歌/主歌结构，没有情感起伏

## 7. AI 歌手的发音技巧 {#7-phonetic-tricks-for-ai-singers}

AI 歌手不识字——它们靠发音。帮助它们：

发音重拼：
- 按单词的**发音**拼写："through" -> "thru"
- 专有名词的失败率最高——尽早测试
- "Nous" -> "Noose"（强制正确发音）
- 用连字符引导音节："Re-search"、"bio-engineering"

演唱控制：
- 全大写 = 更响亮、更强烈
- 元音延长："lo-o-o-ove" = 持续/花腔
- 省略号："I... need... you" = 戏剧性停顿
- 连字符拉伸："ne-e-ed" = 情感拉伸

始终：
- 拼出数字："24/7" -> "twenty four seven"
- 空格分隔缩写："AI" -> "A I" 或 "A-I"
- 先用 30 秒的短片段测试专有名词/不常见单词
- 一旦生成，发音就固定了——在生成前在歌词中修正

## 8. 工作流程 {#8-workflow}

1. 先写概念/钩子——情感核心是什么？
2. 如果是改编，映射原始结构（音节、押韵、重音）
3. 生成原始素材——在结构化之前自由头脑风暴
4. 将歌词草稿填入结构
5. 朗读/唱出来——发现卡顿，修正节奏
6. 构建 Suno 风格描述——描绘动态旅程
7. 在歌词中添加元标签以指导演唱
8. 至少生成 3-5 个变体——把它们当作录音试唱
9. 挑选最好的，使用扩展/继续功能在有潜力的部分上构建
10. 如果意外产生了很棒的东西，保留它
预期：每生成 3-5 次才能得到 1 次好结果。反复修改是正常的。
在扩展部分，风格可能会发生偏移——扩展时请重新明确流派/情绪。

## 9. 经验总结 {#9-lessons-learned}

- 在风格字段中描述动态 ARC（如“从低语到爆发再到低语”）远比仅列出流派重要得多——这能为 Suno 提供一张“表演地图”。
- 在仿作中保留部分原歌词，能增强辨识度和情感分量——听众能感受到原作的“影子”。
- 歌曲中的桥段是转换意象的最佳位置：在保留原曲情感功能（反思、转折、揭示）的同时，将原曲的具体指代替换为你主题的隐喻。
- 在副歌/标签中使用单音节词替换，是保持节奏同时改变含义最干净利落的方式。
- 在风格字段中描述一个鲜明的人声角色，比任何单个元标签都更能带来显著差异。
- 不要死守规则。如果某句歌词打破了节拍但冲击力更强，就保留它。感受才是关键。技巧服务于艺术，而非相反。
